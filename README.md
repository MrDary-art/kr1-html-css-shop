# Учебный frontend-проект kr1-html-css-shop

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

На текущем этапе создана техническая база проекта: локальный и удалённый
Git-репозиторий, базовая HTML-страница, файл стилей, настроена публикация
через GitHub Pages.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений (пока пустая, отслеживается через `.gitkeep`);
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5;
- CSS3;
- Git;
- GitHub;
- GitHub Pages.

## Текущий статус

Создана базовая структура проекта:

- создан локальный Git-репозиторий;
- создан удалённый репозиторий на GitHub;
- выполнены первые коммиты;
- создана ветка `feature/start-page` и выполнен Pull Request;
- Pull Request объединён с веткой `main`;
- настроена публикация через GitHub Pages.
