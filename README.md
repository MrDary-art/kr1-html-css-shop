# Учебный frontend-проект kr1-html-css-shop

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

На текущем этапе создана техническая база проекта: локальный и удалённый
Git-репозиторий, стартовая HTML-страница с формой заявки в модальном окне,
файл стилей, JavaScript-файл, настроена публикация через GitHub Pages.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт для работы модального окна и формы заявки;
- `images/` — папка для изображений (пока пустая, отслеживается через `.gitkeep`);
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5;
- CSS3;
- JavaScript (базовый уровень);
- Git;
- GitHub;
- GitHub Pages.

## Текущий статус

Создана базовая структура проекта и стартовая страница:

## Реализованные элементы интерфейса

- шапка сайта с навигацией;
- hero-блок главной страницы;
- блок преимуществ проекта;
- карточки популярных товаров;
- боковой информационный блок `aside`;
- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
